# AI Jobs Impact and Upskill Advisor

## About the Project
AI Jobs Impact and Upskill Advisor is a web-based career guidance tool that helps users understand how Artificial Intelligence may impact different careers and identify skills they can develop to prepare for the future.

## Features
- Explore the potential impact of AI on different job roles.
- Select existing skills using a checklist.
- View a skill coverage score.
- Get a personalized 30-day upskilling roadmap.
- Print or save the roadmap as a PDF.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Project Purpose
This project is developed as a career-awareness and upskilling guidance tool for students and job seekers in the age of Artificial Intelligence.

## Disclaimer
The current version uses rule-based logic for career impact insights and skill recommendations. It does not use a live AI API or a trained machine learning model.
